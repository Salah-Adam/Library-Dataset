# Library-Dataset
SQL Based Project

## Project Objective
- The main purpose of creating the project was to practice my SQL skill.
- So using my own skill on analysis, I wanted to answer some questions and derive insights from that dataset.

## Dataset Used
- <a href="https://github.com/Salah-Adam/Library-Dataset/blob/main/tables%26insertions.sql">Dataset</a>

## Questions
  - Find Total number of books in the library.
  - Find Average number of days members keep a book before returning it.
  - Find Months with the highest number of books issued/borrowed.
  - Find Number of employees in each branch.
  - Find employees and managers they report to
  - Find Top 10 books with the highest rental price.
  - Find Top 5 members who borrowed the most books.
  - Find List of all book categories and the number of books in each.
  - Find Top 3 most preferred book categories among members.
  - For each month, identify the category with the highest number of books issued/borrowed.
  - Find Top 3 publishers based on the number of books in the library.
  - Find Top 3 authors based on the number of books in the library.
  - Identify members with overdue books (assuming a 30-day return period). Display the member's name, book title, issue date, and days overdue.
  - Generate performance report for each branch, showing the number of books issued, the number of books returned, and the total revenue generated from book rentals.
  - Identify books that have been borrowed the most.
  - Determine which days of the week see the most book rentals.
  - Which employees issue the most books?

## Insights Include:
- The dataset covers two months of library rental data from different branches with issued and return statuses.
- I found which days of the week see the most book rentals. Also Among March and April, I foundout that March is the month that highest number of books issued.
- The data also covers the top 10 books with highest rental price.
- Top 3 most preferred book categories among members and top issued book categories of each month as well as top 5 borrowed books.
- I identified members with overdue books (assuming a 30-day return period).
- I also generated performance report for each branch, showing the number of books issued, the number of books returned, and the total revenue generated from book rentals.
